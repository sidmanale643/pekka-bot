Data

Conversation history is stored in this browser and does not sync. Bot memory is stored by the Pekka server, and files live in each bot's sandbox.

How it works

Each bot has a role, a default task, a sandbox and a memory. Every task you send starts a new agent run in that bot's sandbox.

How do I get started?

Create a bot with a name, role and default task. Open it to run the default task or send something new.

What does a bot remember?

Open Details, then Memory, to read and edit its preferences and knowledge. Conversation history is kept in this browser and is separate from bot memory.

How do scheduled tasks work?

Ask a bot to schedule a task, then check it under Details, then Schedules. The local scheduler must be running for scheduled tasks to execute.

Where are my settings saved?

Your profile, preferences and history stay in this browser and do not sync between devices. Export your history from Settings to keep a copy.
